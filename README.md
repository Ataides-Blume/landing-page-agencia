# Bem-vindo(a) à Landing Page - Agência XYZ

Olá! Seja muito bem-vindo(a) ao projeto de **Landing Page Agência XYZ** desenvolvido para praticar e aprimorar habilidades em **HTML5**, **CSS3** e **CSS Grid Layout**.  
Fique à vontade para explorar, estudar e se inspirar!

## Sobre o Projeto
Este projeto é uma **Landing Page** criada com o objetivo de treinar conceitos fundamentais de desenvolvimento web e criação de layouts responsivos.

## Funcionalidades
- Estrutura de layout utilizando **CSS Grid**.
- **Header** fixo com logotipo e menu de navegação.
- **Menu hamburguer** para navegação em dispositivos móveis.
- **Footer** com informações adicionais.
- Efeitos de **hover** em botões e links.
- Aplicação de **opacidade** para efeitos visuais.

## Tecnologias utilizadas
- HTML5
- CSS3
- CSS Grid
- Font Awesome (para ícones)
- Google Fonts (tipografia)

## Estrutura do Layout
- **Header**: logo e barra de navegação.
- **Seções**: conteúdo dividido em grid para melhor organização.
- **Footer**: informações complementares.
- Layout adaptável para diferentes dispositivos (responsivo).
